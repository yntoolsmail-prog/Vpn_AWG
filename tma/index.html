⚠️ Важно
Один гаджет = один профиль. Не используйте один конфиг на нескольких устройствах — подключение будет нестабильным. Создайте отдельный профиль для каждого гаджета.
🔧 Исключения — настраиваются в карточке устройства → «Исключения». Позволяют пропускать банки, госуслуги и другие сайты напрямую, минуя VPN.
🔄 При смене конфига не забудьте переподключиться к VPN.
📱 Два приложения на выбор
AmneziaVPN — раздельное туннелирование, для телефонов и планшетов.
Только нужные сайты идут через VPN, остальные — напрямую.
AmneziaWG — лёгкий клиент, для ПК и телевизоров.
Весь трафик через VPN или с настраиваемыми исключениями.
📲 Подключение через AmneziaVPN
1. Установите AmneziaVPN: Android — Play Market, iOS / Mac — App Store.
2. Здесь: «Устройства» → откройте устройство → нажмите 🔗 AmneziaVPN.
3. Ссылка скопируется в буфер обмена.
4. В AmneziaVPN: нажмите + → вставьте ссылку в поле «Введите ключ» → Добавить.
5. Включите VPN — готово!
Ключ начинается с vpn://. QR-код для AmneziaVPN не подходит.
💻 Подключение через AmneziaWG
1. Установите AmneziaWG: Android — Play Market, iOS — App Store, Windows/Mac — amnezia.org.
2. Здесь: «Устройства» → откройте устройство → нажмите .conf в Telegram или QR-код.
3. В AmneziaWG: нажмите + → «Добавить из файла» или «Сканировать QR».
4. Включите тоннель — готово!
🌐 DNS — почему это важно
Если VPN вдруг перестал подключаться — скорее всего сменился IP сервера, а ваш роутер или провайдер ещё не узнал об этом. DNS на устройстве кэширует старый адрес.
Решение: настроить быстрый DNS прямо на вашем устройстве (не в приложении VPN).
Основной: 1.1.1.1 (Cloudflare)   Резервный: 1.0.0.1
📱 Android:
Настройки → Подключения → Другие настройки → Частный DNS → ввести one.one.one.one
Или: удержать Wi-Fi сеть → Изменить → Дополнительно → DNS 1: 1.1.1.1, DNS 2: 1.0.0.1
🍎 iPhone / iPad:
Настройки → Wi-Fi → (i) рядом с сетью → Настроить DNS → Вручную → удалить старые → добавить 1.1.1.1 и 1.0.0.1
💻 Windows:
Панель управления → Центр управления сетями → Изменить параметры адаптера → ПКМ на Wi-Fi → Свойства → IP версии 4 → Свойства → вручную: 1.1.1.1 и 1.0.0.1
🖥 macOS:
Системные настройки → Сеть → Wi-Fi → Дополнительно → DNS → + → добавить 1.1.1.1 и 1.0.0.1
После настройки DNS изменения IP-адресов будут доходить за 2–5 минут вместо нескольких часов.

Тип подключения

Домен — рекомендуемый вариант. Подключается по доменному имени сервера: стабильно работает при смене IP и не требует обновления конфига.

IP-адрес — прямое подключение без DNS. Подходит если DNS-резолвинг недоступен или очень медленный.

Резервный — альтернативный адрес. Используйте если основной вариант не устанавливает соединение.
